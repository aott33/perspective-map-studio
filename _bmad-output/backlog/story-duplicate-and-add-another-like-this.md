# Duplicate a map item and "Add another like this", kind and form fields copied

## Description

Parked by the owner on 2026-11-06 when entry 5 of epic-editing was split (its R10). From the properties panel's footer, Duplicate makes a copy of the selected item and "Add another like this" picks up the Point, Line or Area tool for its kind; both copy the kind and the kind's form fields, never the name, the location or the asset link. The kind buttons already add another item of the same kind in one click with the tool staying in hand, so this pays only once items carry kind fields worth copying (epic-editing entry 6).
