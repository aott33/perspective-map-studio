Fix: a hover tint built on the card surface token with a fallback (and every `var(--neutral-30)` hover given one), checked over Satellite in both themes. Reproduced on the showcase over OpenStreetMap in the light theme too (owner screenshot, 2026-10-30). Same bar, same build: the colon after the count is its own span in the bar's flex row, so the gap puts a space before it ("Needs you 3 :"); tuck it against the count (`NeedsYouControl.ts`, `.mapstudio-needs-colon`).
