- (decision) Owner chose the coaching path; scope is viewing and editing (import/export and phone only where they touch those screens).
- (decision) Owner pain with the template map and editor: looks cobbled together, not connected, hacky like a workaround.
- (decision) Owner goal: a tool that looks complete, professional and easy to use.
- (decision) Owner reference: Atlist (atlist.com/help-center) - likes its professional look and its View/Build modes (see the map, then edit it); more complex than needed, a starting point, not to replicate.
- (event) Import imports/atlist-1.webp: Atlist editor screenshot supplied by the owner (see conversation 2026-10-26).
- (event) Import imports/atlist-2.webp: Atlist editor screenshot supplied by the owner (see conversation 2026-10-26).
- (event) Import imports/atlist-3.webp: Atlist editor screenshot supplied by the owner (see conversation 2026-10-26).
- (event) Import imports/atlist-4.webp: Atlist editor screenshot supplied by the owner (see conversation 2026-10-26).
- (decision) Entering edit: both - an Edit switch on the map shown only to users with an editing role, and the component can also be opened straight into edit mode by the integrator (prop).
- (decision) Screens: usually wide screens, sometimes laptops; the owner found Atlist's docked rail plus list plus properties layout fine on a laptop.
- (decision) No Publish step: saves are live (owner, tentative: 'I don't think at least').
- (decision) Editor item list: grouped by place (field, then pad, then what is on it), with items needing attention first; a Sort by dropdown lets the user change the order.
- (decision) Operator popup, in order: comms (and data age), 2 to 3 key values, alarms; the link to the item's page is an icon in the popup header (an open/pop-out icon), not a body button.
- (decision) Adding an item: both - kind buttons for the common kinds plus generic point, line and area tools (kind picked in the form).
- (decision) Placing an item: click the map and drag to fine-tune is the main way; typed coordinates are the backup. Address or legal land description search not chosen as a main way.
- (decision) Snapping: free drawing by default; snapping is a toggle the editor turns on (overrides the earlier snap-by-default idea; the PRD's snapping requirement stays, only its default changes).
- (decision) Undo: both - a visible Undo (button plus Ctrl+Z) for this session's changes even after they saved, and a tucked-away Recent changes panel from the edit record with revert per change.
- (decision) A bulk change undoes as one step.
- (decision) Bulk selection: both - in the list (checkboxes, shift-click range, select all in a group or filter) and on the map (box or lasso).
- (decision) Bulk edit form shows only the fields the selected items share; a field whose values differ shows Mixed; a changed field applies to all selected items.
- (decision) View mode legend: collapsed to a button, opens on request (new need; no FR named a legend before).
- (decision) View mode shows a Needs you summary: count of sites in alarm, comms lost or stale; clicking lists those sites (as the template panel does).
- (decision) View mode search: always visible, top-left.
- (decision) Layout: direction A, Docked studio (Atlist-like mode rail, docked list, docked properties with Details/Style/Link tabs, floating draw toolbar top-centre), as a starting point; owner notes it is busy and may be simplified.
- (decision) Kinds screen: only sets up kinds the project already defines (kind list stays read-only from the host adapter, AD-4/AD-16); no adding kinds here.
- (decision) Kinds screen paths: a tag browser shows one example asset's tags and turns the pick into a path relative to the asset (typed paths remain possible); needs a Gateway tag-browse lookup (new need, unverified).
- (decision) Kinds screen preview: the editor chooses which item the live preview uses.
- (decision) Kinds screen section order: Icon, Key values, Comms, Alarms, Popup, then Style rule last (it builds on the key values).
- (decision) Phone popups: bottom sheets (PRD), a deliberate change from the template's chip row and top sheets; flagged for engineering review (ER-27).
- (decision) Phone view: Needs you and search share one top bar that expands; bottom-right stays clear for the App Bar toggle.
- (decision) Phone editing entry: an Edit button inside the item's bottom sheet, editing that one item (move point, edit properties); no map-wide Edit switch on the phone.
- (decision) Phone point move: tap Move, the map moves under a fixed centre crosshair, tap Done (or Cancel).
- (decision) Import: guided steps - preview on map plus table, map columns to fields, match rows to assets (confident ticked, doubtful flagged), summary (new / updated / skipped), then Import.
- (decision) An import undoes as one step.
- (decision) Layers: only the basemap switch (none, OpenStreetMap, satellite) for now; reference layers and land grids later.
- (decision) First run: an empty map shows a short checklist (Set up your kinds, Add or import items, Check the operator view).
