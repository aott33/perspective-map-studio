Findings (none changes module behaviour in the version pull request):

- **`module_version` is `dev` in a signed build.** `mapstudio_schema_version` recorded `dev` for both migrations: `MapStudioServices.moduleVersion()` reads the gateway jar's `Implementation-Version`, and no jar's manifest carries one. Only that audit column is affected, but `module_version` is part of the public contract (`docs/contract.md`, the map store schema) and a row written by a published 0.2.0 cannot be corrected later. Under the plan's rule (a defect found here stops the release and becomes its own fix) this blocked the tag. **Fixed before the tag (owner decision 2026-10-27, plan Decision 9, gate G4 cleared):** the root build writes `Implementation-Version` = the Gradle version into every module jar's manifest (the tag in a release, `x.y.z-SNAPSHOT` locally), `ModuleVersion` reads it (the package's version, else the manifest of the jar the class came from; `dev` only for a class outside a jar), `GatewayJarManifestTest` fails when the gateway jar's manifest lacks the attribute and `MigratorTest` checks the migrator records the version it is given. A build with `-PreleaseVersion=0.2.0`, as `build-signed.sh` passes the tag, shows `Implementation-Version: 0.2.0` in `gateway-0.2.0.jar` inside the `.modl` **[build]**; the published release's rows are checked on the real stack (owner steps). The `dev` rows of the rehearsal stay in the throwaway stack only.

- **Finding: the certificate bundle must be PKCS#7.** The first throwaway build failed the template's `modl.py inspect` with a traceback from `openssl pkcs7`: the Gradle plugin copies the configured certificate file into the module as `certificates.p7b` without converting it, and `build-signed.sh` gave it the PEM certificate that `keytool -exportcert -rfc` writes, a bare certificate rather than a PKCS#7 bundle. `build-signed.sh` now wraps the certificate in a PKCS#7 DER bundle (`openssl crl2pkcs7`), as the other vendors' modules ship it; `modl-verify.sh` refuses a `certificates.p7b` that `openssl pkcs7` cannot read (and fails if openssl is missing); `scripts/ci/test-signing.sh` has a negative case for a bare certificate.
