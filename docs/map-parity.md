# The template's map, item by item

The `ign-scada-template` map (its `docs/map.md`, section 5, owner 2026-10-21) is the parity list
for Map Studio's view mode (epic 3, R5; prd FR-34). This checklist maps each of its eleven items
to **met** (where, and how it is checked) or **listed for ER-27** (the engineering review of alarm
presentation and the layout departures, epic 3 entry 12). Entry 7 built the marker and line items and
entry 14 arranged the controls as designed; entries 2, 3, 8 and 9 own the rest, as the table says.

Labels: **[live 8.3.10]** seen on the dev stack (`e2e/tests/labels.spec.mjs`); **[build]** unit
tested in node (`web/typescript/__tests__/`); **[ER-27]** to the engineering review.
